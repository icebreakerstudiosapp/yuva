# yuva

Yuva uygulamasının GitHub Pages sitesi: açılış sayfası (`index.html`) ve gizlilik politikası (`privacy.html`, yalnızca İngilizce).

Yayın adresi (Pages açılınca): `https://icebreakerstudiosapp.github.io/yuva/`
Play Console'a verilecek gizlilik politikası adresi: `https://icebreakerstudiosapp.github.io/yuva/privacy.html`

Uygulama Play'de yayınlanınca `index.html` içindeki `LIVE = false` değerini `true` yap.
